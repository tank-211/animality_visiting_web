# Animality Pets — Website

Responsive React + Vite website for Animality Pets, Nashik.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

Import this GitHub repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`. No backend environment variables are required for the current static site.

## Before public launch

Review the displayed contact details, pet availability, product names/prices, testimonials and imagery. The current enquiry form is a front-end demo and does not transmit messages; connect a real form endpoint before accepting customer enquiries.
